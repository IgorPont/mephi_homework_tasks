# Scintillation Detector

Сессионное задание по дисциплине **"Классическое машинное обучение"**

## Описание задачи

Необходимо выполнить автоматическую кластеризацию сигналов сцинтилляционного детектора на 3 кластера:

- `0` -> первый тип сигналов
- `1` -> второй тип сигналов
- `2` -> аномальные, смешанные или неоднозначные сигналы

Задача решается методами машинного обучения без учителя с последующей интерпретацией результатов.

Итоговое качество решения проверяется на Kaggle с использованием метрики `accuracy`.

## Исходные данные

Основной файл `Run200_Wave_0_1.txt` содержит данные о сигналах сцинтилляционного детектора.

Каждая строка соответствует одному сигналу:

- первые 4 столбца -> метаданные
- следующие 500 столбцов -> временные отсчеты сигнала

В ходе первичного анализа было установлено:

- размер датасета: `23479 x 504`
- пропущенные значения отсутствуют
- все признаки представлены числовыми значениями
- импульсы в исходных данных направлены вниз относительно базовой линии

## Основные этапы решения

1. Загрузка и первичный анализ данных
2. Разделение данных на метаданные и временные отсчеты сигналов
3. Визуализация исходных сигналов
4. Предобработка сигналов:
    - расчет базовой линии по первым 50 отсчетам
    - вычитание базовой линии
    - инверсия сигнала
5. Извлечение признаков:
    - базовая линия сигнала
    - шум
    - индекс пика
    - амплитуда
    - площадь под сигналом
    - площадь после пика
    - короткое и длинное окна сигнала
    - PSD-признак
    - длительность сигнала выше уровня шума
    - признаки хвоста
    - признаки затухания
6. EDA рассчитанных признаков
7. Анализ корреляций между признаками
8. Масштабирование данных
9. Обучение нескольких моделей кластеризации:
    - `KMeans`
    - `GaussianMixture`
    - `AgglomerativeClustering`
10. Сравнение моделей по внутренним метрикам кластеризации:
    - `silhouette_score`
    - `calinski_harabasz_score`
    - `davies_bouldin_score`
11. Подбор физически интерпретируемого правила на основе PSD
12. Формирование итогового `submission_final.csv`
13. Проверка результата на Kaggle

## Предобработка сигналов

Визуальный анализ показал, что исходные импульсы направлены вниз относительно базовой линии.

Поэтому для каждого сигнала использовалось преобразование:

```text
processed_signal = -(raw_signal - baseline)
```

После такого преобразования основной импульс становится положительным, что позволяет корректно рассчитывать амплитуду,
площадь под сигналом, положение пика и признаки хвостовой части.

## Итоговый подход

Лучший результат показал физически интерпретируемый подход на основе признака `psd`.

Признак `psd` отражает соотношение короткой и длинной частей импульса и позволяет разделять сигналы с разной формой
хвоста.

Итоговые пороги:

```text
psd < 0.2075 -> исходный кластер 0
psd > 0.2380 -> исходный кластер 1
0.2075–0.2380 -> исходный кластер 2
```

Так как алгоритмы кластеризации присваивают номера кластеров произвольно, была выполнена перенумерация классов:

```text
исходный кластер 0 -> итоговый класс 1
исходный кластер 1 -> итоговый класс 0
исходный кластер 2 -> итоговый класс 2
```

Итоговая логика:

```text
psd < 0.2075 -> класс 1
psd > 0.2380 -> класс 0
0.2075–0.2380 -> класс 2
```

Стандартные модели кластеризации позволили получить базовые результаты, однако наилучшее качество показал физически
интерпретируемый подход на основе PSD-признака.

Итоговое решение является воспроизводимым, интерпретируемым и основано на форме сигнала, что соответствует физическому
смыслу задачи.
