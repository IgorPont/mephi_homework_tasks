# Курсовая работа по дисциплине "Классическое машинное обучение"

### Описание проекта

Целью курсовой работы является исследование данных о химических соединениях и построение модели машинного обучения,
позволяющие прогнозировать показатели эффективности соединений против вируса гриппа.

В качестве целевых показателей рассматриваются:

- `IC50, mM` -> показатель ингибирующей концентрации
- `CC50, mM` -> показатель цитотоксической концентрации
- `SI` -> индекс селективности

### Задачи работы

В рамках курсовой работы решаются следующие задачи:

1. Регрессия для `IC50, mM`.
2. Регрессия для `CC50, mM`.
3. Регрессия для `SI`.
4. Классификация: превышает ли `IC50, mM` медианное значение выборки.
5. Классификация: превышает ли `CC50, mM` медианное значение выборки.
6. Классификация: превышает ли `SI` медианное значение выборки.
7. Классификация: превышает ли `SI` значение 8.

### Особенности предобработки

Из признаков исключаются:

* служебные столбцы вида `Unnamed:*`
* целевые столбцы `IC50, mM`, `CC50, mM`, `SI`

Для задач классификации целевые переменные формируются на основе порогов:

* `IC50, mM` > median(`IC50, mM`)
* `CC50, mM` > median(`CC50, mM`)
* `SI` > median(`SI`)
* `SI` > 8

### Примечание

Показатель `SI` рассчитывается на основе `IC50` и `CC50`,
поэтому при построении моделей необходимо учитывать риск утечки данных.
Утечка данных возникает в том случае, если в признаки модели попадает информация,
которая прямо или косвенно связана с целевой переменной и не должна быть доступна модели на этапе предсказания.
Например, если модель обучается предсказывать значение `IC50`, но среди признаков остаются `CC50` и `SI`,
то модель может использовать зависимость между этими показателями,
а не выявлять закономерности по молекулярным дескрипторам.
В результате качество модели на тестовой выборке может быть искусственно завышено.
Поэтому при формировании матрицы признаков исключены не только сам целевой столбец,
но и производные показатели, рассчитанные с его использованием.
