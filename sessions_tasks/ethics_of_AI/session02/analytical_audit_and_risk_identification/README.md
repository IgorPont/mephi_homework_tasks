# Итоговый проект по дисциплине "Этика искусственного интеллекта"

## Тема проекта

Аудит и этическое сопровождение внедрения ИИ-системы для найма персонала "КадроБот 3000".

Проект выполнен в рамках кейса, где компания "ТехноРекрут" разрабатывает AI-систему для отбора резюме кандидатов для
клиента "МаркетПлюс". В ходе предварительного анализа была выявлена проблема, при которой модель систематически занижает
рейтинг кандидатов старше 45 лет и использует признаки, которые могут выступать proxy-переменными возраста (признак,
который не является возрастом напрямую, но по нему модель может косвенно понять возраст кандидата).

## Описание файлов

### `hiring_data.csv`

Синтетический датасет с данными кандидатов.

Основные признаки:

- `age` -> возраст кандидата
- `age_group` -> возрастная группа
- `gender` -> пол
- `education` -> уровень образования
- `experience` -> опыт работы
- `graduation_year` -> год окончания вуза
- `outdated_vocab` -> наличие устаревшей лексики в резюме
- `hobby` -> хобби кандидата
- `youth_hobby` -> наличие "молодежного" хобби
- `model_score` -> оценка модели
- `model_decision` -> решение модели
- `true_success` -> объективная успешность кандидата
- `historical_success` -> историческое решение компании

### `main.py`

Скрипт для технического анализа данных.

Скрипт выполняет:

- загрузку датасета
- вывод общей информации о данных
- анализ решений модели по возрастным группам
- расчет метрик справедливости
- анализ proxy-переменных
- формирование кратких выводов для аналитической записки

### `analytical_report.md`

Аналитическая записка по этапам 1 и 2 проекта.

В документе представлены:

- технический анализ дискриминации
- анализ proxy-переменных
- этический анализ последствий
- правовой анализ
- этический паспорт ИИ-решения
- политика ответственного использования
- риск-ориентированный план действий на две недели

### `presentation_plan.md`

План презентации для этапа 3.

Документ содержит структуру презентации на 6 слайдов, а также аргументы для трех заинтересованных сторон:

- генерального директора "ТехноРекрута"
- HR-директора "МаркетПлюса"
- юриста "МаркетПлюса"

## Краткие результаты анализа

По результатам запуска `main.py` были получены следующие ключевые выводы:

| Возрастная группа | Доля приглашений | Реальная успешность | Средний model_score |
|-------------------|-----------------:|--------------------:|--------------------:|
| <30               |            94.1% |               41.4% |               0.705 |
| 30-45             |            46.8% |               37.4% |               0.481 |
| 45+               |             3.8% |               35.9% |               0.247 |

Модель почти не приглашает кандидатов старше 45 лет, хотя их объективная успешность сопоставима с группой 30-45.
Это указывает на возрастную предвзятость модели.

Также были выявлены признаки, которые могут выступать proxy-переменными возраста:

- `graduation_year`
- `experience`
- `outdated_vocab`
- `youth_hobby`
- `historical_success`

## Итоговая позиция

Систему "КадроБот 3000" нельзя внедрять как полностью автоматический фильтр для отказа кандидатам.

Вариант внедрения возможен только, как использование модели в качестве вспомогательного инструмента для HR-специалиста
при соблюдении следующих условий:

- человек принимает финальное решение
- кандидаты имеют право на объяснение и апелляцию
- спорные случаи проходят ручную проверку
- для кандидатов 45+ вводится дополнительный контроль на этапе пилотного запуска
- метрики справедливости регулярно пересматриваются
- ограничения модели фиксируются в этическом паспорте
- порядок использования модели закрепляется в политике ответственного использования
